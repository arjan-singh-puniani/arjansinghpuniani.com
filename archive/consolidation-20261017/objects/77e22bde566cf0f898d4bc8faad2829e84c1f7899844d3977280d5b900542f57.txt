## Exact gaps in the current shoulder subset

The production manifest does **not** currently contain separate meshes for:

- supraspinatus tendon
- infraspinatus tendon
- teres minor tendon
- subscapularis tendon
- long-head biceps tendon
- glenoid labrum
- glenohumeral joint capsule
- subacromial-subdeltoid bursa
- coracoacromial ligament
- coracohumeral ligament
- glenohumeral ligaments
- axillary nerve
- suprascapular nerve
- musculocutaneous nerve
- brachial plexus shoulder components
- anterior/posterior circumflex humeral arteries as separately named production meshes
- acromion as a separate selectable mesh
- coracoid process as a separate selectable mesh
- glenoid as a separate selectable mesh
- greater tuberosity as a separate selectable mesh
- lesser tuberosity as a separate selectable mesh
- bicipital groove as a separate selectable mesh

These are therefore **not synthesized in v0.5**.

## What v0.5 improves without inventing anatomy

- All four cuff muscles are forced into a strong visible state in shoulder presets instead of inheriting the generic muscle ghost state.
- Deltoid components can be progressively ghosted or removed using source geometry.
- Source-supported anterior/posterior/superior/cuff/biceps/vascular views control camera and per-structure presentation.
- “Insertion context” shows cuff muscles with the humerus but explicitly does not draw fabricated footprint polygons.
- Spatial comparison mode emphasizes two verified source structures without inferring a clinical relationship from proximity.
- Locate and rebuild practice use exact source structure identity and registered source position.
- Rebuild scoring uses translation distance to the registered source position. Individual structure rotation is not yet part of direct manipulation, so rotational accuracy is not claimed.
- Shoulder labels can be pinned to moving 3D structures.
- Material rendering is deepened with restrained surface variation and a softer fill term. The variation is a visualization treatment and does not represent histologic fibers.

## Fidelity conclusion

The current data can support a much better educational shoulder experience, but it cannot become a genuinely high-fidelity cuff/tendon/labrum/capsule exhibit without an additional verified dataset or a more granular BodyParts3D subset. The software upgrade is worthwhile now; anatomical-source expansion remains the limiting factor for the next fidelity jump.
