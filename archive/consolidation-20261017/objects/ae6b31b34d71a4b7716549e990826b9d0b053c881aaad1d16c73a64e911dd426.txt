## Safe installation

The installer accepts the audited GitHub baseline and the earlier chat-generated upgrade variants. Unknown local changes cause it to stop before writing.

From the repository root:

```bash
python3 portfolio_upgrade/apply_portfolio_upgrade.py --repo . --check
python3 portfolio_upgrade/apply_portfolio_upgrade.py --repo . --apply
```

Then:

```bash
cd arjan-portfolio
npm run lint
npm run typecheck
npm run test
npm run build
```

Do not deploy unless all four pass.

Then inspect `/`, `/work`, `/notes`, `/about`, and `/contact` at mobile and desktop widths.

## Restore

```bash
python3 portfolio_upgrade/apply_portfolio_upgrade.py --repo . --restore
```
