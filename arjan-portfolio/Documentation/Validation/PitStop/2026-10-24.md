## Performance and remaining limits

The final overview reports about 242 draw calls and 29,654 triangles. Static instancing reduced calls from the first implementation's approximately 450. Repeated seeking preserved allocated geometry/texture counts after warm-up. Hidden mechanical geometry is uploaded when inspection is first shown, so that first view legitimately increases GPU allocations; it is not a leak.

Chromium reported `ANGLE ... SwiftShader Device ... SwiftShader driver`, a software renderer. Final brief playback samples ranged from 6 to 12 fps; the last saved sample was 7 fps. The requested desktop 60 fps and mobile 30 fps targets have **not** been demonstrated. Physical-device GPU profiling and cross-browser validation remain required before calling this fully performance-qualified production software. Adaptive pixel ratio/shadows and paused render-on-change are implemented, but no real-device speed claim is made.

Articulated crew motion is procedural, not calibrated motion capture or full contact/IK simulation. Traffic uses an explicit conflict window, not a collision predictor. The pit timing covers a short local segment, not a full real circuit pit lane. Strategy uses synthetic linear tire wear and a constant-pace rival. Real timing import, professional race optimization, a persistent tire inventory across double-stack cars, physical hose dynamics and full season-specific hardware are outside this implementation. Audio event synthesis was integrated; audible speaker output was not assessed. WebGL construction fallback was tested; forced context-loss/restoration was not part of the automated browser run. The original OpenGraph mechanical preview image is retained.

## Local handoff

Run `npm run dev` and open `/playground/pit-stop`, or `/pit-stop-lab/index.html` directly. Use Run stop, then change Rear-right extra alignment to explore a measurable delay. Mechanics inspects the selected wheel at the same timestamp. Timing expands event tracks, telemetry and experiments. Strategy compares three stop choices using this experiment's modeled loss.

The model and source citations are documented in `public/pit-stop-lab/MODEL.md`. All parameter defaults are explicitly illustrative.
