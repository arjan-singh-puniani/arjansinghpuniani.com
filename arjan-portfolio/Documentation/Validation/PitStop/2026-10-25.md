## Performance and scientific limits

The last brief playback sample reported 375 draw calls and 83,684 triangles with the reference ghost enabled. The saved software-rendered sample was 11 fps. Earlier short samples varied; this is not a stable hardware benchmark. Chromium identified SwiftShader software rendering. Physical desktop/mobile GPU performance and the 60/30 fps targets remain unverified.

The adjacent bays, rack display inventory and monitor artwork are illustrative exhibits. The operational inventory separately counts four allocated replacement wheels per serviced car and is reconstructed from wheel events. Tire logistics, cart capacity, human contact mechanics, constrained IK, real race telemetry and a full professional strategy model are not simulated. Footsteps are authored kinematics. The reference ghost compares vehicle trajectories and does not reproduce a second complete mechanical wheel-service animation. Model equations, defaults and these distinctions are documented in `public/pit-stop-lab/MODEL.md`.

## Reproduce locally

From `arjan-portfolio/`, run `npm run dev`, then open `/playground/pit-stop` or `/pit-stop-lab/index.html`.

For the exact browser checks, serve `public` on port 4173 and the production build on port 4174, then run:

```sh
node tools/pit-stop/browser-qa.mjs
```

`PIT_STOP_URL`, `PIT_STOP_PORTFOLIO_URL` and `PIT_STOP_EVIDENCE` override the defaults.

To explore the upgrade: choose Pit box, run a stop, select Tire preparation or a wheel label, then use Timing → Experiments to pin a run. Change a duration and scrub near departure to see the reference car and current result diverge. Night session and Roof section expose the facility's additional detail.
