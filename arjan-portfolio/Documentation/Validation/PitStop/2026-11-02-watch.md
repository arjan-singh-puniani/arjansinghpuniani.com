## Performance and remaining limits

Hardware checks used Chrome/ANGLE Metal on an Apple M2. At 1440×1000 and DPR 1 an earlier sample was 60.1 fenced draws/s; the final recording-enabled journey measured 30.0. A separate embedded DPR 2 sample measured 52.6 draws/s with internal resolution capped at 1.5×. These are specific samples under different recording/load conditions, not a universal frame-rate claim. Final scene: 93 draw calls, 268,612 triangles, 85 geometries, 7 textures. Repeated workspace transitions retained bounded allocations. Paused settled and offscreen circuit states stop drawing.

Physical phone thermals, battery life, and a full manual assistive-technology audit were not measured. This is an educational visual reconstruction and conditional engineering experiment, not real-time team telemetry, calibrated vehicle dynamics or a validated race-winning system. Subjective design ratings and hiring outcomes are not testable guarantees.

## Reproduction

Run `npm test`, `npm run build`, and `npx eslint --no-ignore` against the changed public modules and QA scripts. Serve the production build, set `PIT_STOP_URL` to its origin, then run `node tools/pit-stop/cinema-qa.mjs`. `PIT_FILM_EVIDENCE` selects the evidence directory; optional `PIT_RECORD_VIDEO=1` captures the browser journey. For existing scripts set `PIT_CHROME_METAL=1` and `PIT_STOP_PORTFOLIO_URL` to the same served origin. Source and camera logic are documented in `public/pit-stop-lab/MODEL.md`.
