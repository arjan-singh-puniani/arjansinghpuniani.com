# Site audit

Audit date: 2026-08-28

## Current architecture

- Next.js 15 App Router with strict TypeScript, React 19, global CSS, and no client-side design-system dependency.
- Typed content in `src/content`, reusable navigation/project components in `src/components`, and statically generated project pages at `/work/[slug]`.
- Existing routes: `/`, `/work`, `/work/[slug]`, `/research`, `/about`, `/cv`, `/contact`, and `/privacy`.
- Existing strengths: concise copy, visible project limitations, per-project evidence records, accessible skip link and mobile navigation, responsive layouts, optimized images, sitemap/robots metadata, and small automated content/component tests.
- Existing visual assets support the neural-engineering and research record without requiring generic stock photography.

## Major weaknesses

- Motorsport appears as a single project card and a homepage sentence; there is no coherent motorsport information architecture or substantive system presentation.
- The existing motorsport project is rendered through the generic project template, so its workflow, evidence status, and safety limitations are not legible at a glance.
- The homepage's orbital idea is largely decorative; it does not provide the requested subtle particle circulation, pointer response, central void, or motion preference behavior.
- The homepage palette diverges from the requested indigo, purple, ivory, muted-blue, and rare-gold system.
- Project-status language mixes lifecycle and evidence states (`Completed`, `Active`, `Prototype`, etc.) without a consistent public taxonomy.
- Metadata does not yet establish `/motorsport` as the canonical hub for trackside medicine, neurotrauma, emergency planning, and risk-management study.
- The repository has no Git metadata in this workspace, so native `git diff` and commit history are unavailable here.

## Major opportunities

- Add a dedicated `/motorsport` hub that separates academic systems studies, exploratory tools, and professional learning.
- Add a custom Sonoma emergency-operations case study with a prominent academic provenance statement and semantic system diagrams.
- Give the neurotrauma toolkit its own evidence-safe workflow page while preserving its draft and non-validated status.
- Use the shared sequence `signal → interpretation → decision → action → feedback` as a quiet connective tissue across neural engineering, reasoning systems, and motorsport.
- Replace the homepage's generic motorsport promise with one concrete, accurately labeled proof point.
- Normalize page metadata, navigation, focus states, reduced-motion behavior, and dark visual system across the site.

## Proposed changes

1. Preserve the existing App Router, typed content model, generated work routes, contact flow, and core research/CV/about content.
2. Add `/motorsport`, `/work/sonoma-emergency-operations`, and a custom `/work/motorsport-neurotrauma-toolkit` presentation.
3. Add reusable accessible system-visual components and an interactive orbital canvas.
4. Add the Sonoma academic study to the project index and homepage selected work.
5. Update global styling to the requested restrained palette and technical editorial direction.
6. Expand `CONTENT_AUDIT.md` with exact public wording, source, evidence status, limitations, and publication decisions for every motorsport claim.
