# Molecular asset provenance

- Source records: PubChem 3D SDF records [CID 1486](https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/cid/1486/record/SDF?record_type=3d) (2,4-D), [CID 1480](https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/cid/1480/record/SDF?record_type=3d) (2,4,5-T), and [CID 15625](https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/cid/15625/record/SDF?record_type=3d) (TCDD).
- Source records are retained as V2000 SDF under `public/agent-orange/source/`.
- Atom coordinates and bond orders are read from the SDF. The generator asserts each formula count before scene creation: 2,4-D C8H6Cl2O3, 2,4,5-T C8H5Cl3O3, TCDD C12H4Cl4O2.
- Generator: `scripts/agent-orange/build_molecule.py`.
- Each compound has an editable Blender scene (`public/agent-orange/{2-4-d,2-4-5-t,tcdd}-pubchem.blend`), browser GLB, and inspected still preview under `public/agent-orange/renders/`.
- Representation: conventional ball-and-stick. Atom radii, bond radii, colors, and lighting are visual choices. These are structural models, not depictions of formulation proportions, environmental exposure, metabolism, or a Parkinson disease mechanism.

Blender 5.3.0 is the verified generator version. The downloaded official Apple Silicon disk image matched SHA-256 `2d802b54766741e612cead50b03ebbc8eb64dadc71eda932573d256b8a784720`. The existing Blender 4.0.2 app was not replaced.

## Whole-brain reference model

- Source: Human Reference Atlas, [Brain, Male v1.3](https://3d.nih.gov/entries/20960?version=1), NIH 3D entry 3DPX-020960; source file is also hosted on the [HRA CDN](https://cdn.humanatlas.io/digital-objects/ref-organ/brain-male/v1.3/assets/3d-vh-m-allen-brain.glb).
- The entry describes a model based on the Allen Human Reference Atlas 3D (2020): one hemisphere was mirrored to form a whole brain and resized to fit the Visible Human bodies. NIH 3D lists the model under CC BY 4.0. The site links to the entry and license.
- The upstream GLB is retained at `artifacts/agent-orange/source/hra-brain-male-v1.3-source.glb`; it is 11,977,312 bytes (SHA-256 `2b9ad5b53e40e9f0936da74f7be38d2eed15604e26358c3870a0ea13499b9a35`). Rebuild the browser asset with Blender 5.3.0: `blender -b --factory-startup --python scripts/agent-orange/optimize_hra_brain.py -- artifacts/agent-orange/source/hra-brain-male-v1.3-source.glb public/agent-orange/hra-brain-male-v1.3.glb`. Each named mesh receives a Decimate modifier at ratio 0.5, preserving all 283 named mesh objects. Blender import reports 653,212 polygon-triangle equivalents before and 326,452 after; output size is 6,323,948 bytes (SHA-256 `310c731d9a5bafaf48fb8e52301360c37d7255add587c091411d4389243daebd`). This cuts the transfer asset by about 47%; simplified geometry is for browser display, not diagnosis.
- This is a generic reference model, not an individual scan, veteran scan, or Agent Orange finding. It is kept separate from CIT168 surfaces because their coordinate systems and registrations were not verified against each other.

## CIT168 subcortical atlas surfaces

- Source publication: Pauli WM, Nili AN, Tyszka JM. *A high-resolution probabilistic in vivo atlas of human subcortical brain nuclei*. Scientific Data (2018), [doi:10.1038/sdata.2018.63](https://doi.org/10.1038/sdata.2018.63).
- Source volume: CIT168 1 mm MNI152NLin6Asym discrete label map, downloaded from [OSF item 2qswg](https://osf.io/download/2qswg); lookup table from [OSF item 6qrcb](https://osf.io/download/6qrcb). AtlasPack records these exact files in its [CIT168 preparation script](https://github.com/PennLINC/AtlasPack/blob/main/CIT168/prepare_atlas.sh).
- Source label map retained under `artifacts/agent-orange/source/` so the raw atlas volume is not served as a website asset; label lookup retained under `public/agent-orange/source/`.
- Selected labels: putamen, caudate, and substantia nigra pars compacta (SNc). The raw label image is decoded in NIfTI axis order and mapped through the file affine; left and right are split at the MNI midline.
- Generator: `scripts/agent-orange/build_cit168.py`.
- Outputs: `public/agent-orange/cit168-subcortical.blend`, `public/agent-orange/cit168-subcortical.glb`, and `public/agent-orange/renders/cit168-subcortical-preview.png`.
- The source is a 1 mm discrete group-template label map from an atlas developed from in-vivo MRI; it is not an individual brain, histology, veteran scan, or Agent Orange finding. The exported surfaces are voxel-remeshed and smoothed for display, so their visible boundaries are not a native-resolution diagnostic segmentation. The rendering omits most other CIT168 nuclei and contains no brain cortex or white matter.
- The upstream [CIT168 code repository](https://github.com/jmtyszka/CIT168-SubCorticalAtlas/blob/master/LICENSE.md) is MIT-licensed. The [atlas paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC5903366/) is CC BY 4.0, and the [OSF project node](https://api.osf.io/v2/nodes/jkzwp/) declares the CC-By Attribution 4.0 International license through its license relationship. The OSF API returned license `563c1cf88c5e4a3877f9e96a`, named “CC-By Attribution 4.0 International”; the downloaded label map and lookup table are files from the CIT168 project. The site credits Pauli, Nili, and Tyszka (2018), links the CC BY 4.0 terms, and discloses remeshing/smoothing changes.

## Cinematic scene

- Editable source scene: `public/agent-orange/agent-orange-film.blend`; deterministic scene builder: `scripts/agent-orange/build_film.py`.
- The 105-second timeline has seven camera-animated 3D shots and reuses the PubChem conformers and CIT168-derived GLB described above. The opening aircraft is a procedural C-123 Provider-inspired schematic; the National Museum of the U.S. Air Force's [Ranch Hand exhibit record](https://www.nationalmuseum.af.mil/Visit/Museum-Exhibits/Fact-Sheets/Display/Article/195955/down-in-the-weeds-ranch-hand/) documents modified C-123 aircraft used to spray Agent Orange. The model is not a reconstruction of a specific aircraft, mission, or site, and no reference photograph is embedded. Terrain and spray are illustrative. Neuron, mitochondrion, and pathway views are educational schematics; the candidate-mechanism shot is labeled as such. The neuron scene includes a rounded soma cutaway, branches, segmented myelin, and terminal vesicles; the mitochondrion is an educational cutaway with simplified inner-membrane folds.
- The current `public/agent-orange/agent-orange-film-silent-review.mp4` is a 105-second H.264 cut at 1920×1080, 24 fps, made from 2,520 Blender Cycles CPU frames. The corrected encode passed a full decode and black-frame scan. The contact sheet is `artifacts/agent-orange/encoded-contact-sheet-1080p.png`; the closing confidence-interval chart is a deliberate static pause.
