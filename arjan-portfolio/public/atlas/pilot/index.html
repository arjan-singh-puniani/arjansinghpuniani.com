Sample decision memo

Illustrative research memo covering three historical U.S. FDA records. Current labeling, comparative outcomes and recall status remain open.

Review question

Which original FDA decisions belong in a U.S. essential-tremor comparison, and which later decision should be tracked separately?

Decision note

Keep two separate rows for the original decisions. Activa uses implanted electrical stimulation. ExAblate Neuro uses focused ultrasound for thermal ablation. Track the later Activa Parkinson’s supplement separately so it does not broaden the historical tremor row.

Open checks

Before using the comparison in a current review, confirm the exact models and applicable labeling. Review comparative clinical evidence separately if the team needs to compare outcomes.

Dated source log

  • Activa Tremor Control System · P960009 · 1997-07-31

    The original PMA authorized unilateral thalamic stimulation for disabling upper-extremity tremor in specified patients with essential tremor or Parkinsonian tremor. FDA approval order statement

  • ExAblate Neuro Model 4000 Type 1.0 · P150038 · 2016-07-11

    The original PMA authorized unilateral thalamotomy for specified adults with medication-refractory idiopathic essential tremor. FDA safety and effectiveness summary, sections I–II, page 1

  • Activa Parkinson’s Control Therapy · P960009/S007 · 2002-01-14

    This later supplement authorized a separate configuration for bilateral GPi or STN stimulation in a specified Parkinson’s disease population. FDA supplement safety and effectiveness summary, sections I–II, pages 1–2
