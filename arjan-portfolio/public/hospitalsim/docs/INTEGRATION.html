# hospitalSIM portfolio integration

The owner authorized replacing the REPLISOME project card on October29,2026. hospitalSIM becomes the first Playground card and gets `/playground/hospitalsim`, `/hospitalsim/index.html` and a `/work/hospitalsim` engineering record. REPLISOME’s original page/assets are preserved unchanged. The optional in-game science workstation embeds its existing same-origin build, pauses the hospital and unmounts on close. It provides no hospital-service bonus.

The source checkout was isolated from current origin/main. No unrelated portfolio content, redirect, security header or original untracked work was changed. Production uses the existing GitHub/Vercel deployment workflow. The private Common Good Site keeps its identity and owner-only audience; its display name becomes hospitalSIM.

`tools/sync-portfolio.py <portfolio-root>` copies the game, reproducible Blender sources, tests and documentation. It deliberately reuses the portfolio’s root REPLISOME assets. Source manifest hashes verify the preserved module and game assets. Only the release record can confirm a successful production deployment.
