## Visual assessment and limits

The supplied reference remains stronger in human anatomy, facial variation, cloth folds, hand/equipment contact and studio-light nuance. hospitalSIM has more circulation floor, repeated procedural figures, approximate interior task poses and grid-based crowd behavior. Faces, garment seams, surface roughness, doorway motion and heading changes have improved; they do not establish parity with the reference or a commercial studio game. The side-by-side presents actual browser capture beside the user-supplied reference, for assessment only.

Actual iPhone Safari, thermal/battery performance, long-session device behavior, VoiceOver user testing and a full accessibility audit remain pending. The in-app test browser keeps inspected pages visible, so an actual hidden-tab event is not verified here; background pause is implemented. A device-local iPhone check/export is provided. Clinical assumptions, usefulness, enjoyment, learning transfer and educational effectiveness require external review and consenting participant evidence. The assessment protocol remains an unvalidated draft.
