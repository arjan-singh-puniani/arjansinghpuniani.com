# Dossier scope and review method

All **91 explained entries** now have an inspectable, downloadable dossier. The original search corpus remains 2,490 records; the dossier corpus is separate and overlaps its original decisions. The 89 marketing applications comprise 85 PMAs and four 510(k)s. BrainGate and cortical cooling retain investigational/public-authorization-not-established status.

The checked public PMA inventory contains **6,505 original/supplement decision records** (85 originals plus 6,420 supplements; provider update 2026-10-12). All 85 original identifiers/dates reconcile to the existing entries. The four 510(k) identities/decisions remain linked to their authentic cached sources. The 351-result FDA recall query (provider update 2026-10-19) yields **349 accepted direct application-linked records** and **two malformed references held separately**. Accepted supplement references normalize to their parent PMA; broad `openfda.*` manufacturer harmonization never establishes a recall join. Positive records preserve product, lot/serial, reason, action, initiation/posting dates and status as supplied. Status is not independently verified current lifecycle. Zero direct matches is not a safety finding.

There are **105 original labeling document links across 76 entries**, plus four clearly separated 510(k) summaries. The other nine PMA entries have no accepted original labeling link yet. Sixty-one exact section headings in 19 readable documents have direct PDF-page links; heading discovery is not section-content review. Original label discovery uses publicly retrieved FDA application pages, including cached web retrieval where direct downloads were provider-blocked. The inventory records access method/date, source URL, missing documents and unavailable text. Original labeling is not certified current.

Six FDA safety/early-alert index pages contain 410 unique notice URLs. Explicit product/class title screening produces candidates, never a confirmed model/application association. Pre-2023 web archives, complete manufacturer notices, enforcement classification reconciliation and MAUDE are outside the checked inventory. All 91 entries now have individual source assessments, including warnings/exclusions where supported. The 349 accepted recall records have source-field audits and explicit anomaly flags; individual unit applicability remains undetermined. Fifteen scope decisions cover 14 unique FDA communications. Three product-specific label gaps remain, and historical/model-limited sources are not certified current. See [LABELING_SAFETY_REVIEW.md](LABELING_SAFETY_REVIEW.md) for the complete ledger and exact limits. No dossier is labeled clinically complete or safe. Broad disclaimers in brief exports are replaced with per-entry coverage, source links and named remaining review tasks.

Reproduce without network or an ingestion database: `python3 ingestion/build_dossiers.py`. It rehydrates the compact `data/dossier-acquisition-index.json` manifest from SHA-256-verified original files in `public/dossier-sources/`. Corrupt sources, inconsistent pagination and incomplete history/recall refreshes fail rather than replace the published collection. New live acquisition is explicit: `npm run dossiers:scope`, `npm run dossiers:acquire` (cached resumable jobs), then `npm run dossiers:build`; use `python3 ingestion/dossiers.py acquire --force` for an intentional refresh. Original labeling discovery is an attributed, separately reviewed inventory, not guessed PDF paths or an automated current-IFU scraper.

The interface lazy-loads `/dossiers/<entry>.json` only after opening Dossier. It offers dated decisions, a labeling-mention filter, original labeling and section links, full affected-product recall detail, reviewed notice-scope decisions, source timestamps/checksums, JSON download and dossier citations in Markdown briefs. Switching entries preserves the chosen detail tab. Data is text/JSON; third-party HTML is preserved as `.txt`, never executable HTML.
