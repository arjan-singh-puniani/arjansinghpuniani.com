# Staff wardrobe assets

Executed Blender 4.0.2 to create seven original game wardrobes. Assets and original geometric role lettering are CC0-1.0, with substantial OpenAI Codex assistance. Real clinical uniforms vary; these are readable game conventions.

| Role | Shared clip base | Visible cues |
| --- | --- | --- |
| Doctor | coat | White coat, navy layer, stethoscope, MD badge |
| Surgeon | clinician | Navy scrubs, cap, mask, SUR badge |
| Nurse | clinician | Teal scrubs, RN badge |
| Nurse practitioner | coat | Shorter white coat, plum layer/lapels, NP badge |
| Physician assistant | coat | White coat, light-blue layer/lapels, PA badge |
| Imaging technologist | clinician | Blue shirt, charcoal utility panels/pouch, XR badge |
| Reception | clinician | Terracotta casual shirt, sand trousers/collar, lanyard, DESK badge |

All fourteen GLBs have one primitive, 39 unchanged joint names/bind matrices, embedded roughness data and **zero animation clips**. Reuse the nine clips from the indicated canonical clinician/coat GLB. High meshes contain 12,582–14,034 triangles; LODs contain 4,024–4,488. Seven LOD files total 1,532,196 bytes. The combined editable Blender source is compressed.

`verify_shared_clips.py` imports the actual base GLB animations and every wardrobe high/LOD GLB, checks identical binds, plays all nine clips, evaluates deformed meshes, and verifies weighted eyelid/jaw/finger motion. All fourteen passed; maximum bind-matrix difference was exactly zero. Original character source/assets remained unchanged. The tracked Python cache was restored to HEAD bytes.

Rebuild with Blender `-b --python blender/staff_roles.py -- --render`, run `verify_shared_clips.py`, then run `assemble.py` with Pillow. Only curated contact sheets/checks are retained; individual render files are regenerated by the build command.

Remaining limits: existing stylized adult anatomy/faces and authored motions; no cloth simulation or clinical validation. Printed badges become too small at distant zoom, so the browser's role labels remain necessary.
