# Building affordances — v12

Each placed object receives a stable ID and bounded history: placement day, visits by member, up to six recent place memories, and favorite members after three completed visits.

- Bench: seating, watching, shared breaks. A bounded sit pose offsets the body onto the bench while keeping the navigation approach clear.
- Plant: admiration/tending opportunity, quiet shared time. Detailed watering hand/prop choreography is not implemented.
- Basket: practice/stretching opportunity. It does not unlock a new training economy.
- Lamp: a quiet-break destination plus the existing visible lamp.

The director asks Nia to choose a placed object according to object type and previous visits, then an available companion. The activity reserves the object and both members. Visit counts and relationship changes commit only after actual arrival and a completed shared interval.

Click a placed object to see its history and affordances. Move keeps the stable ID/history; Escape cancels placement. Return to catalog refunds full purchase cost and clears that place's preferences. In-use objects cannot be moved/removed. Bench navigation obstacles are rebuilt after edits and reload.

Placement remains limited to open floor outside the court. Navigation rejects blocked destinations instead of pretending a straight path through furniture is valid. This is not a full placement-footprint/crowd solver; dense arrangements still need further QA. No new asset packs or currencies were added.
