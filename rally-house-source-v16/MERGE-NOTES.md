# Merge notes

## Branches used

The build uses **Living Club v2 as the simulation spine** and incorporates the strongest architectural / renderer ideas from the earlier 3D vertical-slice branch.

The original Canvas prototype remains preserved in `legacy/` as the visual and interaction reference.

## What was kept from the earlier 3D foundation

- dependency-free custom WebGL2 renderer
- strict TypeScript structure
- procedural modeled environment
- semantic room layout
- soft miniature palette
- custom camera
- procedural character geometry
- deterministic game clock
- data-driven furniture/world content

## What was kept from Living Club v2

- relationships and memories
- autonomous club moments
- daily gentle intentions
- coaching progression
- persistent equipment and decoration state
- deeper Club Book
- richer character identity
- environmental animation
- save-schema migration

## v3 polish additions

- animation-driven racket contact
- serve toss and stroke phases
- tennis-ready and shuffle footwork
- predictive receiver movement
- ball gaze and social gaze
- improved faces / blinking / expression
- camera-aware side-wall cutaway
- curated orbit views
- warm point lights
- cloud shadows and dust motes
- improved tone response
- transparent-object sorting
- richer procedural racket / bounce / net audio

The guiding rule was to improve visible feel before adding breadth.
