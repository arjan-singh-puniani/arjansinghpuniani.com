All ritual objects save bounded completed usage. Watering additionally saves damp-soil cooldown; sketch/erase save actual board geometry; lamps save actual point-light intensity. Supply inspection reports the authored visible stack, without inventing inventory pickup.

Buildable objects use specific mappings: leaves brush, seats sit, tables tea/read, bags kit inspection, racket racks pluck, cones stretch/footwork, hoppers/baskets supply inspection, towels stretch, scoreboard/display read. Unknown catalog types receive no invented ball-feed fallback. Their placement identity/history remains owned by ObjectAffordances.

Clock: 240 full + 240 cancelled + 240 reduced-motion restores, plus three live-time invocation snapshots. Water: actual hand/soil contact; cooldown and reload. Board: sketch → erase → sketch native UI and actual generated ink. Bell/rack: targeted reach and actual owned geometry. Machine: one BallPhysics launch/bounce, rather than repeated fake effect balls. Seats: actual height, approach, release, and seated ball gaze.

Browser coverage, isolated simulation fixtures, measured frame timings and device limits are recorded separately in RALLY-HOUSE-VALIDATION.md. Count is coverage, not a numerical enjoyment score.
