# Authored athlete

Taylor uses a complete, clothed MakeHuman adult mesh, a fitted blue crop top and a chartreuse tennis skirt, ponytail, eyebrows, eyelashes, eyes and an authored dental mesh. Other cast members retain their existing appearance while this hero is reviewed. No user reference photograph is embedded in the assets.

The source geometry, default weights, adult targets and system assets were released under CC0 by the MakeHuman community, Data Collection AB, Joel Palmius and Jonas Hauquier. The skirt is by **MargaretToigo**; the natural skin is by **Bobby_03**, the black ponytail material by **dariush086**, and the authored facial units by **Mika Suominen**, all CC0. The fitted top adapts **HighNeckCropTop by punkduck**, licensed under **CC BY 4.0**; it is fitted, cropped, recolored and combined with the sports shorts. [Creator credits and license links](./CREDITS.html) are also accessible through Club Book → Academy. The CC0 license is in `LICENSE.md`; source URLs and source/runtime SHA-256 checksums are in `taylor/provenance.json`.

To rebuild, place `base.obj`, `default.mhskel`, `default_weights.mhw`, `asian-female-young.target`, `caucasian-female-young.target`, and `universal-female-young-maxmuscle-averageweight.target` from the pinned core revision in a working source directory. Extract the official CC0 system pack to another directory, plus `clothes/punkduck_high_neck_crop_top` from `shirts03_ccby.zip`. Extract `skirts01_cc0.zip` into the same directory; this bake uses `clothes/toigo_skirt_with_lace_ruffle` with its lace section removed, a clean upper-thigh tennis hem, and refitted hip weights. The opaque sports shorts finish inside the skirt. Extract `skins01_cc0.zip` beneath the core working directory as `skins/`; the required skin is `skins/skins/bobby_03_young_female_hairless/Young_Female_Hairless.png`. Extract `faceunits01.zip` beneath the core directory as `faceunits/`, and `system_hair_materials01_cc0.zip` into the system directory. The latter supplies `hair/ponytail01/dariush086_ponytail01_black/ponytail01_black.png`.

Run the project's `tools/bake-authored-athlete.py CORE_DIRECTORY SYSTEM_DIRECTORY assets/characters/taylor` using Python with NumPy and Pillow. It uses the installed `/Applications/Blender.app/Contents/MacOS/Blender` (validated with Blender 4.0.2) to fit sportswear against the anatomical body and transfer the actual surface weights. The mouth helper reduces the licensed dental mesh to the existing character budget while retaining its jaw morph; facial shape and normal channels are baked from the authored units. Build inputs and temporary unclothed fitting geometry stay outside the public release.

The runtime has no new dependency. The existing anatomical pose drives the character, props, captures and replay; two foot bones preserve planted shoes, and the source forearm twist joints distribute wrist rotation. Authored facial channels, including matching surface-normal changes, are bounded to smile, mouth opening, blinking and brow raising; a fifth channel closes the authored fingers around the racket. Anatomical wrist endpoints keep the forearm connected while the game continues to anchor the grip. The renderer verifies UV and displacement data and uses the same alpha masks in color and shadow passes. This is a review candidate, not a claim of studio-quality art or animation.
