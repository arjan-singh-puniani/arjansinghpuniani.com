# Authored athlete

Taylor, Coach Contessa, Lucresia and Barbara use the complete clothed MakeHuman adult body and Microsoft Rocketbox head, eyes and expression channels. The other women have painted face albedo, shaped heads, coordinated fitted kits and individual bun, ponytail or bob hair. No user reference photograph is embedded in the assets or supplied to imagegen.

The source geometry, default weights, adult targets and system assets were released under CC0 by the MakeHuman community, Data Collection AB, Joel Palmius and Jonas Hauquier. The skirt is by **MargaretToigo**; the natural skin is by **Bobby_03**. These assets are CC0. The fitted top adapts **HighNeckCropTop by punkduck**, licensed under **CC BY 4.0**; it is fitted, cropped, recolored and combined with the sports shorts. [Creator credits and license links](./CREDITS.html) are also accessible through Club Book → Academy. The CC0 license is in `LICENSE.md`; source URLs and source/runtime SHA-256 checksums are in `taylor/provenance.json`.

## Arjan upper body

Arjan's jersey and exposed arms use the same pinned CC0 MakeHuman core topology, default weights and nineteen-bone runtime contract. It replaces the separate procedural shoulder/torso pieces; the existing head, neck, hands, wristbands, shorts, legs, shoes, racket and gameplay pose remain. Skin beneath the shirt is omitted.
