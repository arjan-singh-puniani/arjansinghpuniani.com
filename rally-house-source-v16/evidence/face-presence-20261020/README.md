# Face presence

1. **Wrong:** Taylor’s rest face read as stern and mask-like: heavy painted makeup, reddish eyes, a rigid hair cap and an ineffective smile. The old blink snapped closed. Stronger authored mouth opening also exposed the absence of teeth.
2. **Cause:** Facial movement was approximated by coordinate-based Gaussian offsets without corresponding surface-normal changes. Materials and corneal response did not support the intended adult look. The model had no dental geometry.
3. **Smallest complete fix:** Bake Mika Suominen’s CC0 facial units into the existing four expression channels, with their matching normal changes. Use Bobby_03’s natural skin, dariush086’s black ponytail material and an amber-brown eye material; give the cornea a bounded sky reflection. Smooth the blink close/open curve. Fit the licensed dental mesh and reduce it with preserved jaw attributes, within the existing character triangle budget. The same actor, contact rig, expressions and replay path remain in use.
4. **Regression:** Full npm test passes. Strict intake accepts reviewed normal channels and rejects nonfinite/excessive offsets. Real asset checks cover grip/wrist/feet, translated-root registration, upper/lower tooth motion, render purity and continuous blinking. Native GPU readback uses the production vertex shader to check actual positions and unit normals for neutral, smile, mouth, blink, brow, real talk values, frown and combined expressions. Eight states pass with no GL/page errors. The shader uses 15 of the Mac’s 16 available vertex attributes. The complete hero has 39,870 triangles. Desktop and touch tests each produced a real three-shot rally and returned to the club cleanly. All 106 source/served release artifacts match. Real unpaused championship ABBA medians remain 16.7 ms; before p95 is 16.7 ms and after is 16.8 ms, adding one draw call. These timings cover this Mac and sampled scenes.
5. **Actual perceptual result:** Matched native portraits at the same actor time, camera and lighting show a softer smile, natural skin, black ponytail and brighter eyes. `comparison.webp` is a crop/composition of those actual runtime captures, not generated artwork. Expression views show full eye closure, moving facial shading and the fitted jaw/teeth. The blink reaches full closure without its previous instantaneous jump. `motion.webm` records four seconds of the production actor’s conversation/blink update in the diagnostic view (241 rendered frames, zero GL errors and all tracks released). The real in-club phone workflow recorded 162 samples, synchronized within 8.0 ms, released every media track and returned zero Axe violations.
6. **Colleague-send test:** Closer in facial presence, still **no**. The hairline, eye gaze, natural seated cloth folds, broader acting and whole-cast art consistency remain below the requested bar. Human appearance feedback remains pending; the goal remains active.

Baseline: commit 628e0fbc, with matching runtime and assets. Portraits use the production Character and Renderer on an isolated diagnostic stage; these are distinct from the live championship performance run. `qa/face-expression.mjs` reproduces the GPU expression readback and snapshots. Expression snapshots include full-range diagnostics as well as ordinary talk values; a full-range jaw pose is not a claim of polished acting. The sky highlight is a bounded artistic approximation, not a room reflection probe.
