2. Cause: the authored kit still retained its jersey component. Existing skirt clearance covered the thighs but missed the central pelvis/shorts volume.
3. Smallest complete fix: fit punkduck's HighNeckCropTop to the existing adult body, crop its waist and neckline, color it blue and combine it with the protected shorts in the existing kit mesh/atlas. Keep the same nine parts and shared rig. Extend the existing color/shadow cloth correction with a pelvis bound, derived from the recorded rig pose, so live play and replay use the same correction.
