# Hand continuity and forearm roll

1. **Wrong:** Hands snapped when sitting, drinking or preparing to play. Palm turns also pinched the forearm.
2. **Cause:** Hand orientation/grip followed discrete state flags while the body blended continuously. The imported forearm twist weights had been merged, concentrating rotation at one joint.
3. **Smallest fix:** Damp hand controls in the existing pose, interpolate rigid orientations through the existing replay path, and retain two original distal forearm joints. Share palm roll across those joints while preserving the authoritative wrist/grip endpoints. No new runtime dependency.
4. **Regression:** Full npm test passes, including 315 hand transition updates, render purity, 448 rigid interpolation samples, authored skin weights, wrist/grip endpoints, legacy rig registration and replay. Native state recordings have zero GL/page errors and release all tracks. Final phone capture recorded 162 samples, stayed within 8.4 ms of the video, released all tracks and had zero Axe violations. All 104 source and served artifacts match. Live unpaused championship ABBA runs retained a 16.7 ms median and 16.8 ms p95 at a 2112×1320 canvas. The accompanying phone and live performance reports cover this Mac, not all devices.
5. **Perceptual result:** Before, changing state visibly flattened/turned the hands before the arms moved. After, hands turn with the transition and ordinary forearms retain their shape better. Measured zero-time hand surface jumps were 0.261/0.217/0.185 game units for sit/ready/drink, now zero. The comparison is the same production Character/Renderer on an isolated diagnostic stage, not the club scene or artwork. Each short WebM shows the actual transition. The frame timing report separately measures the real unpaused championship.
6. **Colleague-send test:** Closer, still **no**. Extreme wrist bends, seated shorts deformation, face-obscuring racket framing and whole-cast consistency remain visible blockers. This pass improves continuity; it does not establish final art quality. Human appearance evaluation remains pending and the goal remains active.
