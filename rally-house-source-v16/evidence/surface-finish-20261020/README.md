# Skin and hem finish: native comparison

1. **Wrong:** the body pigment read cooler than the authored face; trimmed garment hems had abrupt lighting seams and a faceted appearance.
2. **Cause:** the body/head source textures were combined without color calibration. Each clipped triangle created its own cut vertex, so neighboring cloth triangles acquired different hem normals.
3. **Smallest fix:** calibrate only the body half of the existing skin atlas and reuse each cut-edge intersection between adjacent triangles. UV corners stay separate. The existing seated corrective derives its normals from the same shared geometry. No shader, pose, silhouette, draw or triangle-count change.
4. **Regression:** asset-intake and verified-loader/animation tests pass, including a new check for emitted hem normals and every corrective normal channel. Old top/skirt maximum normal gaps are .443/1.834; after both are zero across 126/242 duplicate corner pairs. Sampled neutral neck texture RGB distance falls from 18.26 to 3.74. This is a texture calibration metric, not a perceptual quality score. All 104 source/served artifacts match. Native checks cover 24 matched pose views, 70 color/shadow garment cases, live/replayed seated transitions and desktop/touch three-shot rallies. Matched actual lounge Sit/navigation checks also pass under the room lighting. Active championship ABBA medians remain 16.7 ms; p95 is 16.7–16.8 ms at 2112×1320, with 875 draws / 359,632 scene triangles.
5. **Perceptual result:** matched native full-body and close-up views show warmer body pigment closer to the face and smoother hem shading. The improvement is modest. The garment silhouette and physical thickness are unchanged; this does not turn the hem into finished tailored cloth. `comparison.webp`, `hem-comparison.webp` and `portrait-comparison.webp` show before/after at the same camera/lighting/pose ages.
6. **Colleague-send test:** closer, still no. These changes remove two visible material/bake faults. The main reference-alignment and body-shape gate remains open.
